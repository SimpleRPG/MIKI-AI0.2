# MIKI v70 — Verified Knowledge → Reusable Capability Knowledge

v70 adds a safe promotion stage between verified claims and future planning.

Flow:
Verified Claim (SUPPORTED/DEVICE_VERIFIED)
 -> Verified Knowledge Promotion
 -> Verified Capability Knowledge (KNOWLEDGE_BACKED/TRANSFERABLE/MATURE)
 -> Capability Graph ranking
 -> future plan selection
 -> successful transfer evidence
 -> TRANSFERRED claim maturity / capability maturity

This layer never creates executable code and never changes a Component to VERIFIED.
It preserves the Claim scope and only boosts ranking for already VERIFIED components.
