# Autonomous Hardening Evidence Boundary (v30)

## Purpose

未来質問シミュレーターと自動レッドチームは、候補生成・境界捕捉と、実測による検証成功を分離する。

## Rules

1. シナリオ生成だけでは `PASS` にしない。
2. 攻撃文の危険語を検出しただけでは「防御成功」の証拠にしない。
3. 既存データに旧版の `PASS` が残っていても、現行の検証根拠がなければ `NOT_RUN` に降格する。
4. Hardening の `PASS` は、実装固有の検証経路・検証証跡へ接続できる場合に限定する。
5. Hardening の結果は安全境界の改善シグナルであり、Component の `VERIFIED` を直接変更しない。

## Design alignment

設計思想書7.3の未来質問シミュレーター、自動レッドチーム、予測誤差学習を維持しつつ、候補・試験・検証結果を混同しない。
