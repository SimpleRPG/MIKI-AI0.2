# MIKI-AI0.2 非LLM中心設計思想 実装更新 v47

## 対象
設計思想書 10〜14章、13.3/13.4/13.5/13.6 および 20章の原則を実装へ反映。

## 変更点
- LLM移管比較から疑似LLMレイテンシ、疑似LLM出力、乱数一致率を廃止。
- シャドー比較は同一入力に対する実測LLM出力/実測非LLM出力/実測時間/意味一致率を要求。
- 移管メトリクスは保存された比較記録から再計算。
- `NON_LLM_LIMITED` / `NON_LLM_DEFAULT` への昇格には実測記録数と品質・決定論性の閾値を要求。
- 非LLMハードウェア経路はCPU-firstへ変更。NPU/GPUは実装・実測プロバイダーが存在する場合のみ実行バックエンドとして報告する。
- 決定論性ハッシュに処理時間や乱数を混ぜず、入力・要求型・採用部品・出力コード等からSHA-256を算出。
- 推薦処理から固定50点などの架空スコアを排除。評価軸と根拠が不足する場合は推奨を確定しない。ユーザーが明示的に選択した場合のみ、その価値判断を採用。
- 実機未検証のNPU/GPU性能や「30ms以内」などを実測事実として表示しない。

## 検証境界
TypeScript依存パッケージが作業環境に存在しないため、リポジトリ全体の完全コンパイルは未実施。実機、APK、NPU/GPU、Excel/VBE E2Eも未実施。これらは全実装完了後にまとめて検証する。
