# MIKI 自律改善 作業指示

## 目的
既存の自己改善機構を使って、Termuxから一定時間または無期限で改善サイクルを継続できる状態を維持する。

## 実装要求
1. 改善サイクルを繰り返し実行する
2. `--duration 1h` のような時間指定と `--duration forever` を受け付ける
3. このファイルの指示を既存の作業指示書機構へ渡す
4. サービス群から未整理の対応手段を発見し、能力インベントリへ保存する
5. Ctrl+C/SIGTERMで安全停止する

## 禁止事項
- 指示書から任意のshellコマンドを実行しない
- Evidence/安全ゲートを迂回しない
- 検証なしの変更を成功扱いにしない

## 完了条件
- Termuxでランナーを起動できる
- 指定時間で自動停止できる
- `forever` で継続できる
- 作業指示が取り込まれる
- `runtime/miki_discovered_capabilities.json` が生成される
