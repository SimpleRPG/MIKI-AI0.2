# マイグレーション検証レポート: フェーズ5 自然言語ワークフロー合成エンジン (Workflow Synthesis Engine)

## 1. 概要と設計思想

設計思想 47章 & 35章 第5段階「自然言語からワークフローを作る機構 (Natural Language Workflow Synthesis Engine)」に基づき、ユーザーの自然言語による複合指示を解釈し、46章「能力プラグイン」および tools の実行可能DAG/パイプラインへと自動分解・合成・実行するエンジンを構築・検証した。

さらに、以下の関連サービスを有機的に結合した：
- **第28章 実績コード骨格 (Code Skeleton)**: `codeSkeletonService` による過去に高評価・成功実績のある安全テンプレートの選定・パラメータ注入
- **第10章 総合コード安全準備ゲート**: `codeVerificationService` によるマルチ言語構文整合性、Office 64bit PtrSafe宣言、破壊的コマンド(Kill/Shell)多層スキャン
- **第46章 権限保護原則**: プラグイン追加時にも端末内の正式権限を自動増加させず、未承認プラグインを含むステップで明示的同意ダイアログをトリガーして安全に中断・再開するゲート制御

## 2. ワークフロー合成パイプライン構成

| ステップ順 | ステップ名 | 担当プラグイン / ツール | 主な処理内容 |
|:---|:---|:---|:---|
| 1 | 外部仕様・Web情報調査 | `plugin_web_search` / `tool_gemini_cloud_search` | 公式ドキュメント、API仕様、ベストプラクティスをWeb検索・収集 |
| 2 | ワークスペースファイル解析 | `plugin_code_workspace` / `tool_workspace_search` | 既存コードの依存関係・関連モジュールの特定 |
| 3 | コード理解中間IR & コメント乖離精査 | `plugin_code_understanding_ir` / `tool_code_ir_extractor` | 12段階IR分解、プロシージャ構造・コメントと実装の矛盾検知 |
| 4 | 実績コード骨格(Code Skeleton)探索・適用 | `plugin_code_skeleton` / `tool_code_skeleton_retriever` | 第28章の実績テンプレートから最適な骨格を選定 |
| 5 | 抽象VBA設計仕様書 & 決定表の策定 | `plugin_vba_design_spec` / `tool_vba_spec_designer` | 第26章の決定表(条件と動作)・テストケースを事前設計 |
| 6 | ターゲット成果物生成 | `plugin_safe_computation` / `tool_safe_math` | 仕様書準拠の安全なコード・成果物を生成 |
| 7 | 静的構文検査 & 安全準備ゲート検証 | `plugin_code_verification` / `tool_code_verifier` | 閉じタグ・ブロック整合性・破壊的コマンド静的検査 |
| 8 | 内的自己反証 & 成果物確定 | `plugin_completion_judge` / `tool_completion_evaluator` | エッジケース反証と7項目の完成条件チェックリスト判定 |

## 4. 結論

- **自然言語解析による自動DAG生成**: 単発会話と多段ワークフロー要求を正確に識別し、8段階の実行可能ステップへ分解可能。
- **事前予算見積もり**: 所要時間・トークン数・リスクレベル（ネットワーク権限の有無）の事前算定が正常に動作。
- **安全同意ゲート遵守**: 第46章の「正式権限の自動増加防止」に基づき、未承認プラグインを含む処理は中断し、ユーザー明示承認後に安全に再開・完遂されることを実証。
- **コード骨格・静的検証連携**: `codeSkeletonService` の実績テンプレート適用と `codeVerificationService` の構文・セキュリティ静的検査がパイプライン内で統合稼働することを確認。
